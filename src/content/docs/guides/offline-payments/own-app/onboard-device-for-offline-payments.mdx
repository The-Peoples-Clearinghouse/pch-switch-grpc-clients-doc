`OnboardDeviceForOfflinePayments` registra el dispositivo de un Usuario para que pueda operar pagos offline. El Participante envía la llave pública que generó el dispositivo junto con el resultado de la atestación, y recibe de vuelta el hash de esa llave firmado, más la llave pública con la que se firman los tokens.

![Flujo de registro del dispositivo para pagos offline](../../../../../assets/offline-onboarding-flow.webp)

<Aside type="note">
  Antes de esta llamada, la app debe haber generado su par de llaves y haber obtenido una atestación válida a partir de un [challenge](/pch-switch-grpc-clients-doc/guides/offline-payments/own-app/request-attestation-challenge/).
</Aside>

## Enviar la solicitud

<Tabs syncKey="lenguaje">
  <TabItem label="TypeScript">
    ```typescript
    const attestation = new OnboardingAttestation();
    attestation.setChallengeid(challengeId);
    attestation.setPackagename('mx.mibanco.app');
    attestation.setPlatform('ANDROID');
    attestation.setKeyid(keyId);
    attestation.setToken(attestationToken);

    const request = new OnboardDeviceForOfflinePaymentsRequest();
    request.setSourcefspid('MIBANCO');
    request.setPublickey(devicePublicKey);
    request.setPartyid('10011110002');
    request.setFspid('MIBANCO');
    request.setAttestation(attestation);

    // Envía la solicitud al Switch
    const grpcResponse = await grpcClient.onboardDeviceForOfflinePayments(request);

    // Maneja la respuesta
    const error = grpcResponse.getError();
    if (error) {
      console.error('Error del Switch:', error.getCode(), error.getMessage());
      return;       // no continuar el flujo
    }

    const devicePublicKeyHash               = grpcResponse.getDevicepublickeyhash();
    const minterPublicKeyPem                = grpcResponse.getMinterpublickeypem();
    const minterPublicKeyHash               = grpcResponse.getMinterpublickeyhash();
    const devicePublicKeyHashSignedByMinter = grpcResponse.getDevicepublickeyhashsignedbyminter();

    // Entrega estos datos a la app para que los guarde en su almacenamiento seguro
    ```

## Parámetros de la solicitud

| Campo | Tipo | Requerido | Descripción |
|---|---|---|---|
| `sourceFspId` | `string` | Sí | FSP que origina la solicitud (el Participante). |
| `publicKey` | `string` | Sí | Llave pública que generó el dispositivo para pagos offline. |
| `partyId` | `string` | Sí | Identificador del Usuario (ej. número de celular). |
| `fspId` | `string` | Sí | FSP del Usuario. |
| `attestation` | `OnboardingAttestation` | Sí | Resultado de la atestación del dispositivo. Ver tabla siguiente. |

### OnboardingAttestation

| Campo | Tipo | Descripción |
|---|---|---|
| `challengeId` | `string` | Identificador del challenge con el que se generó la atestación. |
| `packageName` | `string` | Identificador del paquete de la app. |
| `platform` | `string` | Plataforma del dispositivo. |
| `keyId` | `string` | Identificador de la llave del dispositivo. |
| `token` | `string` | Token de atestación emitido por el servicio de integridad de la plataforma. |

## Respuesta exitosa

| Campo | Tipo | Descripción |
|---|---|---|
| `destinationFspId` | `string` | FSP destino de la respuesta (el Participante). |
| `devicePublicKeyHash` | `string` | Hash de la llave pública del dispositivo. Identifica al dispositivo en las operaciones de pagos offline. |
| `minterPublicKeyPem` | `string` | Llave pública, en formato PEM, con la que se firman los tokens. |
| `minterPublicKeyHash` | `string` | Hash de esa llave pública. |
| `devicePublicKeyHashSignedByMinter` | `string` | Hash de la llave del dispositivo, firmado. Permite a otro dispositivo validar la identidad sin conexión. |
| `error` | `ErrorResponse` | Presente solo si no fue posible registrar el dispositivo. |

<Aside type="caution">
  La app debe conservar estos cuatro valores en su almacenamiento seguro: los necesita para firmar pagos, para validar los tokens que reciba y para identificarse ante el otro dispositivo durante un pago offline.
</Aside>
